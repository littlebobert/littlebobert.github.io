# Umete 0.5.3

Umeteは、古いフォームで、フィールドの1行上にあるラベルや空欄内に表示された名前など、より多くのフィールド名を読み取れるようになりました。また、ZIP+4欄や入力直後のフィールドについてAIに問い合わせなくなりました。
