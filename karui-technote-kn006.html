KN006: Benchmarking Private Cloud Compute Against Claude Opus 5.5

Karui

An ongoing benchmark of how well Private Cloud Compute sorts my notifications with Karui’s Second Opinion prompt, compared with Claude Opus 5.5 on the same prompt and graded by hand.

October 29, 2026 · In progress: 87 of 464 notifications so far

Results so far

Karui’s decision is whether to interrupt you. Important notifications come through; Neutral and Spam both stay quiet, unless you turn on the daily summary. So these count only that decision: Important or not.

Private Cloud Compute catches more of what matters, and interrupts more for what doesn’t, such as a delivery update. Opus almost never interrupts for nothing, but missed more than half of my Important notifications. Missing one costs more than an extra interruption, so neither is simply better yet.

Opus is right more often overall, on 12 notifications Private Cloud Compute got wrong against 6 the other way, but that isn’t significant yet (exact McNemar p ≈ 0.24). Neither ever called a notification I graded Important Spam.

Counting Neutral and Spam apart, which matters only with the daily summary on, Opus matched my grade 70% of the time and Private Cloud Compute 60%.

Where both missed

Both missed the same 7 notifications I graded Important, such as an App Store review, a GitHub permissions request, and payment receipts, and both raised the same 2 false alarms. On these the models agree with each other, not with me, so the prompt is the lever: treating account, payment, and review notices as Important would likely help both more than switching models.

How it works

  • I graded 501 notifications from my own History by hand, without seeing Karui’s answer, and left out 31 I graded Unclear and 6 Karui’s rules decided, since no prompt changes those. 464 remain.
  • They’re mostly hard cases: 485 of the 501 changed category after Karui first sorted them, usually because the on-device model was rate limited and a Second Opinion sorted them again. Expect lower accuracy than on a typical day.
  • Each model answers each notification once, with Karui’s Second Opinion prompt as shipped and my sorting settings: Private Cloud Compute through the “Karui Second Opinion” Shortcut on a Mac, Opus through the Claude API at medium effort.
  • Apple limits Private Cloud Compute to about 90 answers a sitting, so this fills in over days; so far 91 of 464. This note will be updated.

For this test I sent my own notifications to Anthropic. Karui itself never does: it uses only Apple’s on-device model and, with Second Opinion on, Private Cloud Compute (KN004). The tool, karui-eval, is in Karui for Mac’s source.

Caveats and next

  • One grader, me, and 87 notifications so far, only 24 of them Important: those percentages could be 20 points off either way.
  • One answer per notification, so this doesn’t show how often an answer changes between runs.
  • Apple can change Private Cloud Compute’s model and limits without notice.
  • Next: extend both to all 464, and try a prompt aimed at the notifications both missed, first on Opus, then on Private Cloud Compute.
