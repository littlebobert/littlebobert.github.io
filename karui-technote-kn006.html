KN006: Private Cloud Compute vs. Claude Opus 5.5

Karui

How well Apple’s Private Cloud Compute sorts my notifications compared with Claude Opus 5.5 compared to my own by manual grading.

October 29, 2026 · Updated October 31, 2026 · In progress: 171 of 464 notifications so far

Results so far

Important notifications interrupt you, so whether something was marked as Important or not is the most important metric.

Winner

Private Cloud Compute catches more of what matters, but interrupts more for what doesn’t, such as a delivery update. Opus almost never interrupts for nothing, but missed more than half of my Important notifications.

Opus matches me more often overall, but that isn’t significant yet (exact McNemar p ≈ 0.27). Private Cloud Compute and Opus each called just one notification I graded Important Spam, and it was the same one: a verification code.

Apple’s on-device model, given the same prompt, nearly ties Private Cloud Compute on Important or not: Private Cloud Compute was right on 22 notifications the on-device model got wrong, against 19 the other way (exact McNemar p ≈ 0.76). It’s much worse at Spam, though. It called 80 of the 171 notifications Spam, against about 31 for the other two, and 8 of those I graded Important.

Counting Neutral and Spam apart only matters if the Daily Summary feature is on. For that Opus matched my grade 69% of the time, Private Cloud Compute 64%, and the on-device model 48%.

Where both missed

Both missed the same 14 notifications I graded Important, and both raised the same 3 false alarms. Five of the 14 are account, payment, and review notices, such as an App Store review, a GitHub permissions request, and payment receipts, and 7 are direct messages from people. To fix these we could probably just adjust the prompt.

How it works

  • I graded 501 notifications from my own History by hand, without seeing Karui’s answer, and left out 31 I graded Unclear and 6 Karui’s rules decided, since no prompt changes those. 464 remain.
  • They’re mostly hard cases: 485 of the 501 changed category after Karui first sorted them, usually because the on-device model was rate limited and a Second Opinion sorted them again. Expect lower accuracy than on a typical day.
  • Each model answers each notification once, with Karui’s Second Opinion prompt as shipped and my sorting settings: Private Cloud Compute through the “Karui Second Opinion” Shortcut on a Mac, Opus through the Claude API at medium effort, and Apple’s on-device model on a Mac, with the prompt sent as one message. That isn’t how Karui’s own on-device sort works: it runs on the iPhone, with the instructions kept apart and a structured answer.
  • Apple limits Private Cloud Compute to about 75 to 90 answers a sitting, so this fills in over days; so far 171 of 464. This note will be updated.

For this test I sent my own notifications to Anthropic. Karui itself never does: it uses only Apple’s on-device model and, with Second Opinion on, Private Cloud Compute (KN004). The tool, karui-eval, is in Karui for Mac’s source.

Caveats and next

  • One grader, me, and 171 notifications so far, only 51 of them Important: those percentages could be about 14 points off either way.
  • One answer per notification, so this doesn’t show how often an answer changes between runs.
  • Apple can change Private Cloud Compute’s model and limits without notice.
  • Next: extend both to all 464, and try a prompt aimed at the notifications both missed, first on Opus, then on Private Cloud Compute.
