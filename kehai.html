Kehai (気配)

Tame your windows
Browse windows intelligently grouped by task, not by app. Quickly return to your last task after an interruption.
Download for macOS (version 0.1.26)
Requires macOS 14 or newer on an Apple Silicon Mac. An OpenAI API key is required to generate task groups.

What it does:

Kehai shows your open windows and Safari tabs in one searchable browser, intelligently grouped by project or task. Now returning to work starts with context.

Privacy:

When Kehai generates groups, it sends OpenAI window and Safari-tab titles, app names, recent focus activity, and small, compressed screenshots of eligible windows. Smart Search sends only your query and window metadata, never screenshots. You can exclude an app from AI queries while keeping it visible in the browser, or exclude it from Kehai entirely.

View the source code on GitHub.

Why “Kehai”?

Kehai (気配) is the sense that something is present without being seen.
