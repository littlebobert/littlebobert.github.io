Kotai

Keep work and personal coding separate in Cursor
Route personal and work projects through separate OpenRouter setups.
Download for macOS (version 0.2.9)
Free and no in-app purchases.

What it does:

Every request from your agent uses a special model prefix that Kotai uses to route the request to your personal setup or your work setup.

Data path and privacy:

Prompt data travels through ngrok, then on to OpenRouter.

View the source code on GitHub.

Why "Kotai"?

Kotai (交代) is the Japanese word for alternation or changeover.

Requirements:

The macOS app requires an Apple Silicon Mac with macOS 14 or newer, a free ngrok account with ngrok set up, and two OpenRouter API keys: one personal and one for work.

Limitations:

Kotai and ngrok must remain running. The ngrok free-plan request and bandwidth limits apply. Anthropic-native clients are not supported.
