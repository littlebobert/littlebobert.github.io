Kotai (交代)

Keep personal and work usage separate in Cursor, etc.
Route personal and work projects simultaneously in Cursor and OpenAI-compatible clients through one stable URL.
Download for macOS (version 0.1.1)
Free and no in-app purchases.

What it does:

Kotai is a macOS menu bar app that routes each Cursor or OpenAI-compatible client request by model prefix. Use kotai/personal/… or kotai/work/… to select an account; Kotai strips the prefix before sending the real model ID to OpenRouter, so both accounts can be used at once.

Data path and privacy:

Prompt data travels through ngrok, then on to OpenRouter.

View the source code on GitHub.

Why "Kotai"?

Kotai (交代) is the Japanese word for alternation or changeover.

Requirements:

The download requires an Apple Silicon Mac with macOS 14 or newer, a free ngrok account with ngrok installed, and two OpenRouter API keys—one personal and one for work.

Limitations:

Kotai, ngrok, and your Mac must remain running. ngrok free-plan request and bandwidth limits apply. Anthropic-native clients are not supported. OpenRouter’s Cursor integration is beta, and some Cursor features may bypass custom API keys or base URLs.
