Changelog

Shadan

0.1.8 (9)

September 29, 2026
  • If Safari doesn’t open its Extensions settings from Shadan’s setup link, Shadan now tells you to quit and reopen Safari, which fixes it.

0.1.7 (8)

September 29, 2026
  • Fixed a bug where changing your topics could make Safari ask you to allow Shadan on other open tabs.

0.1.6 (7)

September 27, 2026
  • Fewer images hidden by mistake. When Shadan is less sure an image matches, it now blurs it instead of hiding it, and “not this” answers now also count for similar-looking images.
  • In the review grid, you can now view the full image before ticking it.
  • Bug reports include more detail about why images were hidden, still with no images, URLs or topic names.

0.1.5 (6)

September 27, 2026
  • Fixed a bug where the link to Safari extension settings wouldn’t open.

0.1.4 (5)

September 27, 2026
  • Improved the control HUD for narrow images.

0.1.3 (4)

September 27, 2026
  • Added acknowledgements to the About window.
  • Moved the “Hide images like this?” bar to the top so it doesn’t overlap X’s controls.

0.1.2 (3)

September 27, 2026
  • Use smaller deltas for updates.
  • Added Japanese UI.

0.1.1 (2)

September 27, 2026
  • Fixed a bug where the macOS app showed a spurious warning about the Safari extension installation.

0.1.0 (1)

September 27, 2026
  • Initial release.
