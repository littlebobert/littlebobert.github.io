Yubi (指)

Translate screens. Type in Japanese.
Fast translation for what’s on-screen. Translate to Japanese as you type.
Join the Beta
Free and no in-app purchases.

What it does:

Press the Action Button and translate what's on screen, or translate what you’ve typed with Yubi keyboard. Yubi uses OpenAI or Anthropic to translate.

Privacy:

Yubi only sends a screenshot or selected text when you ask, and collects no analytics.

View the source code on GitHub.

Requirements:

Requires iPhone with iOS 17 or newer. Enable Yubi Keyboard in Settings and grant Full Access for translation. Screenshot translation uses the Shortcuts app.
